🔌 라즈베리파이 전력 측정 구성도

WattWise 실측 검증 하드웨어 — 경로 A(가전별 스마트플러그)와 경로 B(분전반 CT)를 병행하면 AI Hub 데이터와 같은 구조(총량 ch01 + 가전 채널)가 됩니다.

경로 A — Tapo P110 스마트플러그 권장 · 배선 없음

플러그를 가전과 콘센트 사이에 끼우고 Tapo 앱으로 Wi-Fi 등록 → Pi가 같은 공유기에서 각 플러그의 순시 전력(W)을 로컬 API로 읽음. 전기 작업 전혀 없음. 설치 시간 플러그당 3분.

경로 B — 분전반 CT 클램프 총량 측정 · 주의 필요

ADS1115 핀Pi 5 핀용도
VDD1번 (3.3V)전원
GND6번 (GND)접지
SDA3번 (GPIO2)I²C 데이터
SCL5번 (GPIO3)I²C 클럭
⚠️ 안전: 분전반 커버 개방 작업은 감전 위험이 있습니다. 반드시 메인 차단기를 내리고 CT를 클램프한 뒤 복구하세요. 가능하면 전기 유경험자와 함께. CT는 도선을 자르지 않고 물기만 하는 방식이라 클램프 자체는 비접촉입니다.

소프트웨어 파이프라인 — 측정에서 예측까지

설치 명령: sudo apt install python3-pip → pip3 install tapo torch pandas (경로 B는 adafruit-circuitpython-ads1x15 추가, raspi-config에서 I²C 활성화). 모델 파일은 wattcast_v2.py + 체크포인트 3개(<5MB)만 복사하면 됩니다.
